# Règles du jeu de cartes Bartok

## Objectif et Concept

Le but est de se débarrasser de toutes ses cartes.

**Particularité :** Le gagnant de chaque ronde invente une nouvelle règle qui s’ajoute aux précédentes pour les rondes suivantes. Le jeu devient ainsi de plus en plus complexe jusqu’à ce qu’il soit impossible de continuer. 

Le joker est un atout qui peut être joué sur n’importe quelle carte et n’importe quelle carte peut être jouée sur le joker.



## Préparation
-  **Disposition :** Les joueurs s’assoient en cercle.
-  **Mélange :** Placez toutes les cartes face cachée au centre et mélangez-les.
-  **Distribution :** Chaque joueur pioche 5 cartes.
-  **Pile de défausse :** Retournez une carte et placez-la face visible au centre pour former la pile de départ.
-  **Pile de pioche :** Le reste des cartes face cachée forme la pioche.
-  **Sens de jeu :** Le sens de rotation est vers la gauche.
-  **Premier joueur :** Le premier joueur est le joueur le plus jeune ou le gagnant de la manche précédente.


## Tour de jeu
*   Un joueur peut poser une carte sur la pile de défausse si elle a :
    *   La même **famille** que la carte du dessus.
    *   La même **valeur** (ex: deux 7) que la carte du dessus.
*   Dès qu’un joueur pose une carte légalement, le tour passe au joueur suivant dans le sens du jeu.
*   Si le joueur ne peut pas jouer une carte, il doit piocher une carte dans la pioche. Cela met fin à son tour. 
    *   Si la carte piochée est jouable immédiatement, elle peut être posée avant que le joueur suivant ne joue.
    *   Si la pioche est vide, mélanger toute la pile de défausse (sauf la carte du dessus) pour former une nouvelle pioche.
*   Les jeux doivent être rapides. Toute hésitation excessive peut entraîner une pénalité.
*   Lorsqu’un joueur a une carte restante, il doit prononcer "Bartok" sinon il a une pénalité.

## Fin de la ronde
*   La ronde se termine lorsqu’un joueur n’a plus aucune carte. Ce joueur est déclaré **vainqueur de la ronde**.
*   **Création de règle :** Le vainqueur invente une nouvelle règle qui sera appliquée dès la ronde suivante.
    *   La règle ne doit pas cibler un joueur spécifique (ex: « Saute le tour de Paul » est interdit).
    *   Elle ne peut pas annuler une règle précédente (sauf accord unanime).
    *   Elle doit suivre le format : **« Si [déclencheur], alors [conséquence] »**.
    *   **Veto :** Si tous les joueurs sauf le créateur rejettent la règle, elle est annulée et le créateur doit en proposer une autre.
    *   **Clarification :** Si une règle est floue, n’importe qui peut crier « Timeout ! » pour discuter et clarifier avant de reprendre.
    * Il est possible de s’inspirer d’autres jeux comme *Uno*, mais il est possible aussi d’inviter des nouvelles règles comiques comme :
        *   Si un 10 est joué, le joueur doit lever sa main droite en l’air jusqu’à ce que quelqu’un d’autre joue.
        *   Si un Valet est joué, le joueur doit faire un bruit animalier spécifique (ex: un miaulement). 
        *   Si un Trèfle est joué, le joueur suivant doit dire un mot commençant par la lettre "T" (ou une autre lettre choisie par le groupe) sous peine de piocher deux cartes.

## Pénalités
N’importe quel joueur peut infliger une pénalité. Une pénalité consiste généralement à **piocher une carte**. Un joueur ne peut recevoir qu’une seule pénalité pour une même action, même si plusieurs personnes l’accusent simultanément.

| Infraction | Description | Conséquence |
| :--- | :--- | :--- |
| **Question** | Poser une question (pertinente ou non) pendant le jeu. | Piocher 1 carte. (Peut aussi toucher un observateur pour l’intégrer au jeu). |
| **Jeu Illégal** | Jouer une carte hors de son tour ou ne correspondant pas aux règles. | Piocher 1 carte. |
| **Hors Tour** | Jouer quand ce n’est pas votre tour. | Piocher 1 carte. |
| **Trop Lent** | Ne pas jouer rapidement (environ 3 secondes entre chaque accusation possible). | Piocher 1 carte (peut être cumulatif). |
| **Oubli de "Bartok"** | Avoir une carte restante sans crier "Bartok". La pénalité n’est pas rétroactive si la partie est terminée. | Piocher 1 carte. |
| **Fausse Accusation** | Accuser un joueur à tort d’avoir commis une faute. | Piocher 1 carte. |
