# pdchoco

![pdchoco](pdchco.png)

`pdchoco` est une bibliothèque externe pour Pure Data développée par Thomas O. Fredericks. Elle regroupe un ensemble d'objets utilitaires conçus pour simplifier la programmation, la manipulation de données et la création d'interfaces ou de logiques interactives au sein de vos patchs.

## Installation

### Télécharger

Téléchargez l'archive de la bibliothèque directement à partir du dépôt officiel : [thomasofredericks/pdchoco sur Codeberg.org](https://codeberg.org/thomasofredericks/pdchoco).

![pdchoco sur Codeberg.org](./pdchoco_codeberg.png)

### Déplacer

Déplacez le dossier **pdchoco** (et non pas le dossier racine *pdchoco-main* compressé par défaut) dans le répertoire d'extensions de Pure Data : **Documents > Pd > externals**. 

Si le dossier `externals` ou `Pd` n'existe pas encore sur votre machine, lancez Pure Data une première fois pour qu'il génère automatiquement son arborescence par défaut. Et déplacez ensuite le dossier `pdchoco`.

![Installation du dossier *pdchoco*](./pdchoco_folder.png)
