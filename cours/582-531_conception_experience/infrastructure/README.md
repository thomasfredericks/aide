# 582-531 : Infrastructure logicielle et matérielle

## Installation interactive

Cette infrastructure représente l’environnement technique standardisé utilisé pour la création d’installations interactives complexes en TIM au Collège Montmorency. Elle a été conçue pour enseigner aux étudiants les principes fondamentaux en favorisant une approche modulaire où chaque composant possède une fonction précise et interchangeable.

- Environnement de développement principal :
    - Unity (possiblement Godot ou Three.js)
        - OSC 
        - Spout
- Capteurs et actionneurs :
    - Carte Arduino + Arduino Terminals
    - Raspberry PI ou M5Stack ATOM POE (pour éloigner les transducteurs de l’ordinateur)
    - Pure Data
        - OSC
- Détection d’utilisateurs par caméra : 
    - TouchDesigner avec MediaPipe ou Kinect
        - OSC
        - Spout
- Projection et mapping :
    - OBS
        - Spout
        - HyperHDR	
- Lumières DMX/ArtNet :
    - Pure Data
    - QLC+
    - OSC


## Arcade

Cette infrastructure représente l’environnement technique standardisé utilisé en TIM au Collège Montmorency pour intégrer des jeux dans la borne d’arcade. 

- Environnement de développement principal :
    - Unity (possiblement Godot ou Three.js)
- Boutons et manettes (en commun pour tous les projets de la borne d’arcade) :
    - Carte Arduino + Arduino Terminals
    - Pure Data
        - OSC
- Lumières DMX/ArtNet :
    - Pure Data
    - QLC+
    - OSC
